# 替换为库展示名称

## meta

```json
{
  "schemaVersion": 1,
  "library": "replace-me",
  "summary": "替换为一句话功能摘要。",
  "keywords": ["替换为中文场景", "english keyword"]
}
```

## overview

待核实：功能、适用场景、选型边界和相关库。

## setup

待核实：分别列出 workspace/browser/npm 中真实可用的入口、样式和注册前提。

## vanilla

待核实：核对主入口后编写条目，没有此形态时写“无。”。

## preact

待核实：核对公开 JSX 入口，不能从内部实现推断。

## web-components

待核实：核对标签、公开入口和注册方式，分别记录 attributes/properties/events。

## css

待核实：按 component/js-component/utility/helper 分条，核对类名和组合条件。

## css-variables

待核实：列变量名、默认表达式、含义及取值、声明位置、推荐覆盖节点。

## javascript

待核实：函数、类、对象、常量和配置导出；没有则写“无。”。

## types

待核实：公开类型及继承契约，允许链接到共享 AI 条目。

## recipes

待核实：组合示例，注明环境并包含必要数据、容器与清理。

## constraints

待核实：环境要求、副作用、生命周期和易错点。
