# ZUI 扩展库正式文档规范

## 源文件与事实来源

正式文档源属于 `TARGET_LIB_ROOT`，常见路径为：

```text
docs/lib/<category>/index.md
```

具体分类、额外页面和语法以 `EXT_ROOT` 现有文档与 `ZUI_ROOT` 当前文档管线为准。宿主同步生成目录不属于扩展源码，不手工编辑代替文档源修改，也不纳入扩展提交。

按 [共享工作流](workflow.md) 阅读目标文档和核实本次说明所需的类型、入口或实现；新建或重构页面时再参考相关页面结构。源码和可执行行为是事实来源，不发明 API。

## 内容结构

以下用于新建或重构页面；局部修订只调整请求范围：

- 第一屏给出当前宿主可运行的最小示例，随后按真实能力覆盖使用场景。
- 只记录承诺的 HTML/CSS、Preact、vanilla、自动创建/toggle 等消费方式。
- options/props、事件、方法、公共类型、CSS 类/变量、异步、错误、生命周期和兼容性与源码一致。
- 示例使用真实 `PACKAGE_NAME`、全局导出或宿主文档组件，不假设扩展包名属于 `@zui/*`。
- 使用宿主正式文档的 Example/tabs/Props/ZUI 等语法，不混用调试页 fence。
- 本次新增或改变的链接和资源路径按宿主同步契约验证，不使用本机绝对路径或 `exts/` 符号链接作为公开 URL。

## 修改边界

只修改批准的扩展文档源与必要资源。不得为了让文档成立而悄悄修改运行时 API；发现源码/文档冲突时报告并由相应技能处理。不得手工编辑 `ZUI_ROOT` 的生成文档代替修改文档源，也不得修改宿主依赖或锁文件；文档同步写入遵循 [共享工作流](workflow.md) 的验证隔离与批准规则。

## 联合验证

按共享工作流选择相关 Markdown、链接或示例检查；涉及文档组件、交互示例、导航、资源或同步规则时，再补充必要的宿主文档验证，例如：

```sh
pnpm docs:build:exts
```

确认脚本实际包含 `EXTS_NAME` 与 `ZUI_NAME`。若宿主提供可限定 group 的 prepare/build 参数，优先使用。需要浏览器验证时复用或启动扩展 docs dev，检查本次涉及的示例、依赖、资源、主题或锚点，服务管理遵循 [共享工作流](workflow.md)。

交付时报告扩展源页面、覆盖的消费方式、宿主验证结果、生成目录副作用和仍存在的源码/文档差异。
