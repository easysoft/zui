# CSS 工具类

CSS 工具类用于组合布局、间距、尺寸与外观，可配合[组件库](/lib/)使用。先按下方需求找到对应页面，再查看支持的类名和效果；整体接入方式见[快速上手](/guide/start/)。

## 常用路径

1. 用[显示类型](/utilities/layout/utilities/display.html)或 [Flex 方向](/utilities/flex/utilities/direction.html)确定布局。
2. 用[内边距](/utilities/spacing/utilities/padding.html)、[外边距](/utilities/spacing/utilities/margin.html)和[元素间距](/utilities/flex/utilities/gap.html)安排留白。
3. 用[宽度](/utilities/sizing/utilities/width.html)、[高度](/utilities/sizing/utilities/height.html)和[溢出处理](/utilities/layout/utilities/overflow.html)控制内容区域。
4. 用[外观](/utilities/skin/utilities/solid.html)、[文本颜色](/utilities/typography/utilities/text-color.html)与[字号](/utilities/typography/utilities/font-size.html)完成视觉表达。

## 调整全局风格

单个元素的样式可用工具类组合；需要统一整个界面的配色、字形或间距时，阅读[颜色配置](/guide/config/base/color.html)、[字体配置](/guide/config/base/font.html)和[间距配置](/guide/config/base/spacing.html)。
